Usage

Use your token as a Bearer token in the Authorization header:

curl -X POST /v1/api/chat \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello MIRA"}'

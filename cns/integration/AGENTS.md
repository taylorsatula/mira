## Rules

- Dispatch is structural on the event's exact `__class__.__name__` — `EventBus.publish` is a dict lookup, no MRO walk. Handlers subscribe to concrete class names; a subscription on a category class (`MessageEvent`, `ToolEvent`, `WorkingMemoryEvent`, `ContinuumCheckpointEvent`) hears nothing, because nothing publishes under a category name and `MessageEvent`/`ToolEvent` have no concrete subclasses (`cns/core/events.py`). Failure prevented: silent no-delivery with no error.
- Registration fails fast; publication never validates. `subscribe()` checks the name against `_iter_event_names()` (live `__subclasses__` walk of `ContinuumEvent`) and raises ValueError at graph construction — a renamed event class breaks the boot loudly. `publish()` takes any object: an event with no subscribers, or a non-`ContinuumEvent`, is a silent no-op beyond DEBUG logs. Never wrap `subscribe()` in a tolerant except — that converts the loud boot failure back into silent stranding; on a never-fires handler, suspect the class-name string before the handler body.
- Delivery is at-most-once, synchronous, inline on the publisher's thread: a raising subscriber is logged with traceback and skipped — no retry, no re-queue; remaining subscribers still hear the event; the publisher never learns (`EventBus.publish`). The publishing sites sit on the turn and collapse paths, so a handler failure is a log line nowhere else, and a hung handler stalls every later subscriber and the turn itself — root's degrade-or-propagate doctrine applies with neither retry nor propagation to lean on.
- The graph has two construction sites per boot: `main.py` lifespan (`create_cns_orchestrator()`) and the power-on self-test's `dependency_initialization` check (`utils/power_on_self_test.py` — a child process that tears the graph down after: bus shutdown, singletons nulled). Boot-time side effects in `create_orchestrator()` fire against real infrastructure twice; non-idempotent side effects (infra writes, job registration) do not belong in the factory.
- `create_orchestrator()` order is dependency order, not style: `get_lt_memory_factory()` is called with no arguments in `_get_memory_relevance_service` and `_initialize_segment_collapse_handler`, and raises RuntimeError unless `main.py` built the singleton first (lifespan order owned by root); `WorkingMemory` must precede `ToolRepository` — `ToolRepository.__init__` reaches the bus only through `working_memory.event_bus` for its `SegmentCollapsedEvent` subscription, takes no bus parameter, and skips the subscription silently when `working_memory` is None.
- Trinket add-one: every trinket under `working_memory/trinkets/` is constructed exactly once, here, in `_get_working_memory`'s manual order (gated: `PersonaTrinket` by `config.system.persona_enabled`; `PeanutGalleryTrinket` in `_initialize_peanutgallery_service` by `config.system.peanutgallery_enabled`; `EmailTrinket` in `_initialize_inbox_poller`) — no auto-registration exists. A trinket without a construction line never registers and its slot never reaches a prompt; no error names the omission. Trinket-side steps owned by `working_memory/trinkets/AGENTS.md`.
- Tool-result compaction is DEADHEADED (human-directed; the block comment in `create_orchestrator()` is the record): the hot Valkey cache keeps full tool results, the only bound is `orchestrator._truncate_tool_result`'s raw 31999-char truncation, `cns/services/tool_result_summarizer.py` is unreachable (its subscription never registers), and `config/config.py`'s `worker_pools.tool_result_summarizer_workers` is the knob only the dead module reads. Do not re-enable piecemeal — a compaction redesign replaces the whole block.

## Files

- `__init__.py` — empty; no re-exports. Import `cns.integration.event_bus` / `cns.integration.factory` directly.
- `event_bus.py` — the in-process bus: `EventBus` — `publish`, `subscribe`, `clear_subscribers`, `shutdown` (lifespan exit), `_iter_event_names` (the valid-name roster). Gotcha: `unsubscribe`, `get_subscriber_count`, `get_all_event_types` have no in-tree callers — kept for API symmetry, unexercised; build nothing on them.
- `factory.py` — the DI graph and every boot-time subscription site. Entry: `create_orchestrator` (the ordered wiring), `_get_working_memory` (trinket roster + `load_global_catalog` boot snapshot), the `_initialize_*` family, the `_get_*` singleton accessors, no-op `_register_gated_tools`, `create_cns_orchestrator` (module-level entry). Gotcha: the `ValkeyMessageCache` import and `_valkey_cache` slot are dead — never assigned; the live message cache is constructed inside `ContinuumPool.__init__` (`cns/infrastructure/continuum_pool.py`), so cache wiring does not belong here.

## Wiring

- Boot flow: `main.py` lifespan → `get_lt_memory_factory(...)` (singleton, full args) → `create_cns_orchestrator()` → `initialize_orchestrator(orchestrator)` → `register_segment_timeout_job(scheduler, orchestrator.event_bus)` and `register_sidebar_dispatcher_job(scheduler, orchestrator.tool_repo, orchestrator.event_bus)` (job registration owned by `utils/AGENTS.md`, lifespan order by root). The timeout job publishes `SegmentTimeoutEvent` onto this bus; the dispatcher receives the bus for sidebar agents.
- The subscriber roster is assembled by this factory: every subscription in the process registers during `create_orchestrator()` — directly or in a constructor this file calls, all against the one bus (`EventBus()` is constructed nowhere else). `WorkingMemory` (`ComposeSystemPromptEvent`, `UpdateTrinketEvent`, `TrinketContentEvent`, `SegmentCollapsedEvent` — `working_memory/AGENTS.md`) · trinket bases (`TurnCompletedEvent` — `working_memory/trinkets/AGENTS.md`) · `ToolRepository` (`SegmentCollapsedEvent` — `tools/AGENTS.md`) · `SegmentCollapseHandler` (`SegmentTimeoutEvent`, `TurnCompletedEvent` — `cns/services/AGENTS.md`) · `UserDataManagerCleanupHandler` (`SegmentCollapsedEvent` — `utils/AGENTS.md`) · manifest query service (`ManifestUpdatedEvent` — `cns/services/AGENTS.md`) · `PeanutGalleryService` (`TurnCompletedEvent` — `cns/services/AGENTS.md`) · `InboxPollerService` via its `SegmentPoller` base (`ComposeSystemPromptEvent`, `SegmentCollapsedEvent` — `cns/services/pollers/AGENTS.md`) · `ContinuumOrchestrator`'s own constructor (`SystemPromptComposedEvent` → the composed prompt slots, `SegmentCollapsedEvent` → compaction-baseline invalidation — `cns/services/AGENTS.md`) · this factory's own `TurnCompletedEvent` → `cleanup_ephemeral_tools` lambda (essential set: `ESSENTIAL_TOOLS` in `tools/repo.py`). Full set: `rg '\.subscribe\('`.
- Publishers, by grep (`rg '\.publish\('`): orchestrator (`TurnCompletedEvent`, `ToolResultHistoryCommittedEvent`, `ComposeSystemPromptEvent`, `UpdateTrinketEvent`), collapse handler (`SegmentCollapsedEvent`, `ManifestUpdatedEvent`), segment timeout service (`SegmentTimeoutEvent` — the event's sole bus publisher; `cns/api/actions.py` and the handler's queued-manual path build the event and call `collapse_segment` directly, off-bus), `working_memory/core.py` and the trinket base (`SystemPromptComposedEvent`, `TrinketContentEvent`, `UpdateTrinketEvent`), `PeanutGalleryService` (`UpdateTrinketEvent` into `PeanutGalleryTrinket`), the `SegmentPoller` poll loop (`UpdateTrinketEvent` into its target trinket — `cns/services/pollers/AGENTS.md`), sidebar agents and their tools (`UpdateTrinketEvent`) — all onto the orchestrator's `event_bus`.
- Config gates (consumers tolerate absence): `config.system.subcortical_enabled` false → `_get_subcortical_layer` returns None and the orchestrator runs without the layer; `config.system.persona_enabled` false → no `PersonaTrinket`; `config.system.peanutgallery_enabled` false → no `PeanutGalleryService`/`PeanutGalleryTrinket`; `config.api.subcortical_prefill_warmup` feeds `SubcorticalLayer(prefill_warmup_enabled=...)`. Flag semantics owned by `config/AGENTS.md`.
- lt_memory edge: `get_lt_memory_factory()` supplies `.proactive` to `MemoryRelevanceService` and the collapse wiring — factory contract owned by `lt_memory/AGENTS.md`.
- Singleton pre-warms and seams: `get_embeddings_provider()` (pre-warm only, value unused), `get_llm_provider()`, `get_continuum_repository()`; `SummaryGenerator` built with `llm_provider=None` — `cns/services/summary_generator.py` substitutes the default provider itself; `initialize_continuum_pool(continuum_repo, SegmentCacheLoader)` wires the pool (`cns/infrastructure/AGENTS.md`); `initialize_async_work_barrier()` readies the cross-turn barrier consumed at both turn boundaries (`cns/api/AGENTS.md`); `load_global_catalog()` takes the boot skills snapshot (freshness doctrine owned by `utils/AGENTS.md`).
